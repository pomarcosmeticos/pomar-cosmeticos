# Site Pomar para GitHub Pages

Suba o conteúdo desta pasta para a raiz do repositório publicado pelo GitHub Pages:

- `index.html`
- pasta `assets/` completa

Não altere a estrutura das pastas, porque todas as imagens são locais e usam caminhos relativos.

## Comportamento automático

- A partir de agora, o catálogo usa os novos preços-base (aproximadamente 10% acima dos anteriores).
- Entre **23/11/2026 00:00** e **01/12/2026 00:00** (horário de Brasília), o banner da Black aparece e os produtos recebem 20% de desconto.
- Em **01/12/2026**, o banner e os preços promocionais somem automaticamente; os novos preços-base continuam.
- As abas dos kits permanecem no site depois da campanha, voltando aos preços normais.

## Prévia manual

Para visualizar a Black antes do dia 23, acrescente `?black=1` ao endereço.

Exemplo:

`https://seu-dominio.com/?black=1`
